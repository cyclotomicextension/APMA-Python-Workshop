## 🐍 Save Humans from the AI Farm!

Created by **Additi Pandey and Malindi Whyte**, this beginner-friendly Python workshop puts participants in the role of consultants for an AI-run farm that harvests human ideas. 
Using Python, NumPy, SciPy, and Matplotlib, you’ll model the farm, simulate its population dynamics, and figure out whether the humans survive. 
This repository contains the workshop slides, exercises, and solutions.
